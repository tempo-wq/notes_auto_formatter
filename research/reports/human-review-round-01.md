# Пользовательская проверка — раунд 1, 27 октября 2026

## Что выбрал пользователь

### A

Математическая модель — это приближённое описание какого-либо класса явлений внешнего мира, выраженное математическими символами.

- Математическая модель — DEFINITION_TERM
- приближённое описание — DEFINITION

### B

Электрический ток имеет следующие проявления: нагревание проводников; изменение химического состава проводников; создание магнитного поля.

- Электрический ток — KEY_TERM
- нагревание — KEY_TERM
- изменение химического состава — KEY_TERM
- магнитного поля — KEY_TERM

Границы взяты из ответа пользователя дословно; категории интерпретированы агентом по формулировке вопроса. Это два development-примера с одним респондентом, не окончательный gold и не финальный test. B — сокращённая адаптация исходного текста с явно указанными изменениями.

## Практический результат

Пользователь предпочёл достаточно короткие фрагменты. Например, в B выбраны «нагревание» и «магнитного поля», а не весь список проявлений тока. Этого ещё недостаточно, чтобы зафиксировать общий стиль подсветки для остальных заметок.

Правила нашли один из пяти желаемых терминов без дополнительных TERM. spaCy нашла три, но добавила семь несовпавших TERM. Это конкретный пример компромисса между полнотой и лишними выделениями; он не объявляет победителя и не обосновывает подключение модели.
