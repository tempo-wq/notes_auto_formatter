# Независимая проверка: первый раунд

В первом раунде пользователь получил два коротких development-примера без выдач алгоритмов и назвал шесть желаемых фрагментов. Сырой ответ, его происхождение и точные границы сохранены в `answers-round-01.json` и `human-round-01.jsonl`.

Это **пользовательский выбор фраз**, а не полностью согласованная разметка всех категорий. Категории назначил агент по формулировке вопроса: термин/часть определения для A и ключевые фразы для B. Такое происхождение явно записано в `label_provenance`; не объявляем эти данные окончательным независимым gold. Один респондент и два примера не дают основания выбирать модель.

A — дословное предложение из development-документа wiki_293181. B — адаптированный фрагмент wiki_29983: опущены пояснения в скобках, перечисление сокращено до одной строки. Это учебный пример для согласования границ, не дословная цитата из источника. Attribution и CC BY-SA 4.0: `../datasets/sources.json` и `../datasets/LICENSE.md`. Публикуемые результаты и review-файлы являются продолжением этой адаптации; пользовательские частные заметки здесь не используются.

## Проверяемый процесс

- `prepare.py` создаёт неизменённые тексты вопросов и пустой шаблон ответов. Вопросы не содержат подсказок анализаторов.
- В шаблоне `complete: false`; наличие пустых аннотаций не означает отрицательную разметку.
- `import_answers.py` требует явный ответ для каждого примера, reviewer/evidence, время, совпадающий SHA-256 текста и точные подстроки. Для повторяющейся фразы указывается `occurrence`, начиная с 0. При отсутствии выделений явно указывается `no_highlights: true`.
- Импортёр валидирует данные, но не способен сам удостоверить личность респондента или научную корректность разметки.
- Смещения — Unicode code points, [start,end). Отдельный тест проверяет emoji.
- При импорте этого калибровочного раунда запрещены held-out test-примеры.
- `evaluate_round.py` делает новые предсказания для двух текстов с прежними параметрами. Старые замеры скорости, памяти и silver-результаты не изменяются. Выход — `../results/human-round-01/`.

```sh
PYTHONPATH=research research/.venv/bin/python -m unittest review.test_import -v
research/.venv/bin/python research/review/import_answers.py \
  --packet research/review/round-01.json \
  --answers research/review/answers-round-01.json \
  --output /tmp/smart-notes-reviewed.jsonl
PYTHONPATH=research research/.venv/bin/python research/review/evaluate_round.py
```

Параметры извлечения по этим ответам не менялись. Полная таксономия по ним не сравнивается: пока сопоставляются только термины, сводя DEFINITION_TERM и KEY_TERM в TERM. Выбранная пользователем короткая часть определения в A хранится, но не оценивается как TERM. Следующий раунд должен отдельно согласовать категории и полноту границ на большем количестве development-документов, до работы с закрытым финальным test.
